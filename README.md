🎵 Smart Music Therapy System

The **Smart Music Therapy System** is a Python-based project designed to recommend music playlists based on a user's emotional state. Music can influence mood, help people relax, improve motivation, and provide comfort during different emotional experiences. This project explores the connection between emotions and music by creating a simple system that identifies a user's mood through text input and suggests a suitable playlist.

The system allows users to describe how they are feeling in their own words. Using a keyword-based mood detection mechanism, the program analyzes the input and identifies one of four moods: **sad, happy, stressed, or motivated**. It uses Python string handling and conditional statements to recognize emotion-related keywords such as “sad,” “cry,” “happy,” “excited,” “stress,” “tired,” “angry,” and “motivate.”

The detected mood is then matched with a predefined playlist stored in a Python dictionary. Each mood is associated with a YouTube playlist link and a short explanation describing the purpose of the recommendation. For example, a happy mood may lead to an energetic playlist, while a stressed mood may receive calming music suggestions. Once a mood is identified, the system displays the detected emotion, the reason behind the recommendation, and a clickable link that allows the user to access the playlist directly.

The project is developed using Python and utilizes dictionaries, functions, conditional logic, user input handling, and the IPython Display module to create interactive playlist links. It is implemented in a Jupyter Notebook environment, making it easy to execute, test, and demonstrate.

The main objective of this project is to demonstrate how basic programming concepts can be applied to create a personalized and interactive music recommendation experience. Although the current version uses simple keyword-based detection, it provides a foundation for future development, including advanced emotion recognition using Natural Language Processing (NLP), additional mood categories, personalized music preferences, and a graphical user interface.

Overall, the Smart Music Therapy System combines programming and music to create a simple, mood-aware playlist recommendation experience.
